# Car Price Prediction

## About the Project

This project focuses on predicting car prices using Machine Learning regression techniques. It explores how different car features influence their prices and uses the trained models to generate price predictions.

The project implements Linear Regression and Polynomial Regression to understand and compare different approaches to price prediction.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Streamlit

## Machine Learning Models
- Linear Regression
- Polynomial Regression

## Key Highlights
- Data analysis and preprocessing
- Feature selection and model training
- Regression-based price prediction
- Interactive web application built with Streamlit

## Run Locally

